## 6. 해석 (사실 위주)

- oas 주지표: 베이스 0.708 vs LoRA v2 final 0.681 ± 0.013; 합성 제외 0.290 vs 0.298 ± 0.019.
- oas_code 주지표: 베이스 0.646 vs LoRA v2 final 0.617 ± 0.019; 합성 제외 0.196 vs 0.284 ± 0.022.
- manual 비율: oas 베이스 13.8% vs v2 54.2% ± 2.0%; oas_code 베이스 9.4% vs v2 40.9% ± 6.1%. public 오판(신 정의): oas 베이스 13 vs v2 [0, 0, 0]; oas_code 베이스 18 vs v2 [0, 1, 0] (분모 47).
- LoRA v1 대비(같은 정의): oas 0.689 → 0.681 ± 0.013, oas_code 0.576 → 0.617 ± 0.019; manual oas 46.9% → 54.2% ± 2.0%, oas_code 29.4% → 40.9% ± 6.1%. 구체 응답 정밀도 oas 0.835 → 0.890 ± 0.019, oas_code 0.602 → 0.789 ± 0.025.
- label별(final 평균): oas_code에서 owner_match F1 0.205 → 0.630 ± 0.057, role_required 0.296 → 0.471 ± 0.040로 상승; manual_review_required F1은 0.600 → 0.246 ± 0.034, membership_required 1.000 → 0.568 ± 0.145(support 4)로 하락. manual 비율 상승은 정답이 구체 label인 건을 manual로 답한 결과이며(구체 재현율 ≈ 0.44~0.49), test의 manual 정답은 14/15건뿐이다.
- val-loss 최저 체크포인트는 test macro-F1에서 최종 어댑터보다 일관되게 낫지 않다(seed 42는 하락, 43·44는 상승). 체크포인트 선택을 val loss로 하는 것은 현재 val_v2 구성에서 근거가 약하다.
- seed 간 표준편차(macro-F1 0.013~0.038)는 베이스 대비 차이(oas −0.027, oas_code −0.029)와 같은 크기이므로, 주지표에서 LoRA v2와 베이스의 우열은 확정할 수 없다. 합성 제외·구체 정밀도·public 오판·route_only 보조지표에서는 LoRA v2가 베이스보다 낫고, manual 비율은 베이스보다 크게 높다.
- 합성 58건은 train 합성과 템플릿을 공유하므로 합성 포함 수치는 낙관 편향이 있다. 합성 제외 열이 일반화 근거에 가깝다.
- 단일 데이터 버전 비교이며 data-v1 → data-v2는 라벨 규칙(검수·R1'·R4·variant·VIS cap·쿼터)과 데이터 구성이 함께 바뀌었으므로 어느 요인이 효과를 냈는지 분리되지 않는다.
