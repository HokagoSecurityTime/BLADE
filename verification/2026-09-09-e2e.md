# 전체 서비스 종단 간 검증

- 날짜: 2026-09-09
- 환경: Windows, Python 3.11.9, pytest 9.1.1
- 종단 간 테스트: **1 passed in 1.81s**, 복합 시나리오의 기록 항목 24개 통과.
- 전체 회귀 테스트: **80 passed, 1 skipped, 2 warnings in 3.20s**.
- skip은 실제 LLM 호출 테스트입니다. 이번에는 외부 LLM을 호출하지 않았습니다.
- 경고는 기존 Starlette/httpx 및 anyio deprecated 경고 2건입니다.

## 실행 방법

```powershell
$env:BLADE_E2E_REPORT='C:\BLADE\verification\e2e-live.json'
.\.python\python.exe -m pytest tests/test_e2e.py
```

전체 회귀 테스트에서는 프로세스의 LLM 제공자 설정을 비워 실제 LLM 테스트만 제외했습니다.

```powershell
$env:BLADE_LLM_PROVIDER=''
.\.python\python.exe -m pytest tests
```

## 실험 구성

실제 FastAPI 관리 API와 데모 백엔드를 uvicorn으로 실행하고 aiohttp 프록시를 연결했습니다.
모두 자동 할당된 loopback 포트를 사용하며 HTTP 요청으로 검사했습니다.
SQLite DB, YAML, JSONL은 pytest 임시 경로에 생성합니다. 기존 blade.db/demo.db/policies는 변경하지 않습니다.
종료 시 모든 테스트 서버를 정리합니다.

입력 정책은 이전 [Ollama 결과](classifier-ollama-live.json)를 생성기로 변환한 것입니다.
이번 실험에서는 /generate와 LLM 정확도를 다시 평가하지 않았습니다.
분류 결과가 manual_review_required였던 사용자 조회 정책은 관리 API의 롤백·PUT·승인을 통해
owner_or_admin, users.id 소유권 비교로 명시적으로 검토·수정했습니다.
이 수정은 테스트용 정책에만 적용했습니다.
