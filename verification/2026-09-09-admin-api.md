- 환경: Windows, Python 3.11.9, pytest 9.1.1
- 결과: **관리 API 테스트 4개 통과**, 관련 회귀 테스트 **27개 통과**.
- 실제 서버: `127.0.0.1:8100`, 실제 분류: Ollama `qwen2.5:7b`.

## 구현 범위와 제한

- generator는 정적 경로 조각을 resource로 결합하고 파라미터 표기를 보존합니다.
  GET과 DELETE는 서로 다른 ID이며, 생성된 ID가 충돌하면 409입니다.
- PUT은 status를 제외한 전체 정책을 받으며 id/created_at은 불변입니다.
- 승인 PENDING→ACTIVE, 롤백 ACTIVE→PENDING, 거절 PENDING→REJECTED만 허용합니다.
- POST /detections는 내부용이며 탐지 로그 스키마 그대로 SQLite와 JSONL에 저장합니다.
- 파일 업로드를 위해 python-multipart 의존성을 추가했습니다.
- SQLite와 파일 간 완전한 원자적 커밋은 제공하지 않습니다. 처리 중 예외는 복구하지만
  프로세스 강제 종료·시스템 장애 시 파일 미러 재동기화가 필요할 수 있습니다.
  단일 관리 API 프로세스 운영 기준입니다.
