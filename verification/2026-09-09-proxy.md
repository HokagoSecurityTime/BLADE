## 실행

```powershell
.\.python\python.exe -m pytest tests/test_proxy.py tests/test_admin_api.py tests/test_parsers.py tests/test_schema.py tests/test_demo_backend.py
.\.python\Scripts\uvicorn.exe demo_backend.main:app --port 9000
.\.python\Scripts\uvicorn.exe admin_api.main:app --port 8100
```

별도 프로세스에 로컬 검증용 JWT 시크릿, `BLADE_FAIL_MODE=closed`,
`BLADE_POLICY_POLL_SEC=1`을 설정하고 `python -m proxy.server`를 실행했습니다.
토큰은 검증 프로세스에서 생성했으며 파일에 저장하지 않았습니다.

## 동작 및 제한

- JWT 서명·만료·필수 클레임 검증, ACTIVE 정책 경로 매칭, 7개 label 평가.
- HEAD는 GET 정책을 적용하며 정적 경로를 파라미터 경로보다 우선합니다.
- 정책 스냅샷 갱신과 탐지 로그 전송은 백그라운드 작업입니다.
- SQLite는 mode=ro/query_only로 열며 DB 조회를 작업 스레드로 옮겼습니다.
- 정책 없음·정책 TTL 초과·조회 장애는 fail mode에 따르고, 인가 거부는 항상 차단합니다.
- public/수동 검토 통과, 역할·등급·조직·소유자 일치 및 불일치는 단위 테스트로 확인했습니다.
- 자동 HTTP 테스트는 소유자 200, 타인 403, JWT 누락 401, 미매칭 경로 open/closed,
  쿼리 문자열 전달과 탐지 전송을 확인했습니다.
- 런타임에서 classifier/LLM 호출은 없습니다.
- 영구 로그 재전송 큐, WebSocket, 스트리밍 중계, SQLite 외 DB 지원은 포함하지 않았습니다.
- policy_id/sub가 없는 장애 관측 로그는 새 스키마 필드를 추가하지 않고 빈 문자열을 사용합니다.
